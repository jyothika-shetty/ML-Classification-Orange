# Machine Learning Classification using Orange

## 📌 Project Overview
This project demonstrates classification using Orange Data Mining tool.
Multiple machine learning algorithms were evaluated.

## 📊 Dataset
Features:
- Temperature
- Humidity
- Wind_Flow

Target:
- Status (SAFE / NOT SAFE)

## 🧠 Algorithms Used
- SVM
- Logistic Regression
- Random Forest
- kNN
- Neural Network

## 📈 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- AUC
- Confusion Matrix
- ROC Curve

## 🛠 Tool Used
- Orange Data Mining (No-code ML)
